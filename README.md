# Revi 📖

> 줄을 긋는 순간, 기억됩니다.

종이책의 문장을 카메라로 스캔해 디지털 서재에 보관하는 iOS 독서 하이라이트 앱.

---

## Features

- 📸 **문장 스캔** — 카메라로 책 페이지 촬영 후 OCR 텍스트 인식
- 🖊 **하이라이트 슬롯** — 색상 3종 + 커스텀 RGB 설정
- 📚 **책장 시스템** — 멀티 페이지, 드래그 이동, 표지/책등 표현
- 📊 **월간 독서 리포트** — 매월 1일 AI 생성 리포트 (사서 Revi 코멘트)
- 🔔 **리마인더** — 요일·시간 선택 커스텀 푸시 알림
- 💳 **구독 티어** — Free / Standard / Premium
